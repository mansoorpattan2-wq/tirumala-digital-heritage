# Tirumala experience asset pack

This pack contains eight separately generated AI artistic reconstructions inspired by Tirupati and Tirumala, a scene manifest, generation specifications, and a Codex integration prompt. It is not a complete or survey-accurate reconstruction. No website source was supplied, so this pack has not modified your existing website.

## Use in VS Code
1. Extract this ZIP.
2. Open your existing website project in VS Code.
3. Merge the pack's public/assets/tirumala folder into your project's public/assets/tirumala folder. Do not replace the entire public folder.
4. Copy CODEX_MASTER_PROMPT.md into the project root.
5. Open Codex in that project and send: "Read CODEX_MASTER_PROMPT.md and implement it in this repository. The supplied images are in public/assets/tirumala. Inspect the existing experience, make the changes, and run the available checks."
6. Run the launch command Codex identifies from your actual package scripts.

## Included route
Foothills at dawn; Alipiri-inspired covered stairway; ghat road; Tirumala arrival; Swami Pushkarini-inspired tank; temple entrance by day; temple entrance at dusk; optional festival procession.

The stairs and road are distinct narrative chapters, not a verified continuous walking route. Festival imagery is an artistic recreation of an occasional celebration. Day and dusk scenes are independently generated and do not have pixel-exact geometry continuity.

## Images
Original PNGs are supplied alongside optimized WebP versions and smaller responsive WebP versions. Use the WebP files for the website and keep the PNGs as source assets. The manifest supplies conservative focal points that should be checked against the actual page layout. Flat images support subtle cinematic 2.5D motion, not free-roaming 3D, seamless texture mapping, or 360-degree navigation.

## Authenticity
The assets were generated as new scenes; the previously linked photos were not individually edited or used as attached reference inputs. Architecture, details, people and geographical arrangements may differ from reality. Cross-check sacred architecture against official TTD reference photos before representing it as documentary. No main sanctum interior is included.
